# Architecture decisions

Numbered ADRs in Michael Nygard's format. Numbers are stable and never reused.
A decision that no longer holds is superseded by a new record, not edited.
There is one number space for the whole platform, including decisions that
concern a single app or package. Style guide: [ADR style](../conventions/adr-style.md).

- [0001 Record architecture decisions](./0001-record-architecture-decisions.md) - why ADRs, where they live, and how they relate to the PRD and TRD
- [0002 One language runs on the till and the server](./0002-one-language-runs-on-the-till-and-the-server.md) - the bill printed offline and the bill the server recomputes come from the same code
- [0003 Money is integer paise](./0003-money-is-integer-paise.md) - no floats anywhere; half-up rounding at named points, the CGST/SGST split, largest-remainder discounts and round-off as its own line
- [0004 The billing engine is pure, and the server re-runs it](./0004-the-billing-engine-is-pure-and-the-server-re-runs-it.md) - a deterministic calculation with no I/O; a mismatch is stored as issued and flagged for review, never dropped
- [0005 Tenant isolation is enforced by the database](./0005-tenant-isolation-is-enforced-by-the-database.md) - row-level security the application cannot bypass, a per-table cross-tenant test, and one audited privileged path
- [0006 The till is local-first; the kitchen and guests are online](./0006-the-till-is-local-first-the-kitchen-and-guests-are-online.md) - device first, then an idempotent ordered outbox; sign-out blocked while it holds anything; the kitchen and guest menu pause offline
- [0007 An invoice number comes from a device series](./0007-an-invoice-number-comes-from-a-device-series.md) - one code path online and offline, allocated with the invoice, financial year in IST, codes never reused, a backwards clock blocks billing
- [0008 Financial records are append-only](./0008-financial-records-are-append-only.md) - no update or delete on invoices and payments; cancellation is a new record; documents snapshot what they sold
- [0009 Ids are made by the client](./0009-ids-are-made-by-the-client.md) - time-ordered unique ids created on the device, and an idempotency key on every mutating request
- [0010 A socket event is a notification, not data](./0010-a-socket-event-is-a-notification-not-data.md) - clients refetch on an event and on every reconnect, so a missed event never leaves a stale screen
- [0011 One process and one database until a scale trigger](./0011-one-process-and-one-database-until-a-scale-trigger.md) - API, sockets and jobs in one process on one in-country server; each new piece of infrastructure waits for a named trigger
- [0012 Aggregators sit behind an adapter](./0012-aggregators-sit-behind-an-adapter.md) - one provider-neutral interface; webhooks verified, stored raw and acknowledged at once; all work as retried jobs; switchable per outlet
- [0013 The till and the kitchen are one app; the guest menu is another](./0013-the-till-and-the-kitchen-are-one-app-the-guest-menu-is-another.md) - shared-device screens share an app; the QR menu is separate and stays under 120 KB of gzipped script
- [0014 Built for chains, shipped for cafés](./0014-built-for-chains-shipped-for-cafes.md) - the full tenant → outlet → floor → table hierarchy and later-phase hooks exist now; the screens show one outlet and none of the later features
- [0015 Suspension stops new sales, never record-keeping](./0015-suspension-stops-new-sales-never-record-keeping.md) - a suspended outlet starts no new order, but every synced invoice is accepted and served tables can be billed; post-suspension invoices are flagged
- [0016 Indian time is a fixed offset, never the device's zone](./0016-indian-time-is-a-fixed-offset-never-the-devices-zone.md) - financial year and business date are read at UTC+05:30 by arithmetic, so every till and the server agree; a day-end cutoff is a whole hour
- [0017 A discount comes off the taxable value, and service charge is charged on what remains](./0017-a-discount-comes-off-the-taxable-value-and-service-charge-is-charged-on-what-remains.md) - discount reduces taxable value even on inclusive prices; an undiscounted inclusive line keeps its menu price, a discounted one is re-taxed; service charge is a share of the discounted value, taxed at the outlet rate only when asked
- [0018 Money crosses the wire as a string of digits](./0018-money-crosses-the-wire-as-a-string-of-digits.md) - every amount in JSON is canonical paise digits, never a JSON number or rupees, decoded to the exact integer by one shared definition
- [0019 A caller without a tenant may learn only which tenant holds its secret](./0019-a-caller-without-a-tenant-may-learn-only-which-tenant-holds-its-secret.md) - sign-in, device and refresh tokens and QR codes resolve to their tenant through a few fixed lookups that return only ids; everything else stays isolated
- [0020 Background jobs run as the application role but are installed by the owner](./0020-background-jobs-run-as-the-application-role-but-are-installed-by-the-owner.md) - the job queue has its own schema; the owner installs it in the migrate step, and the running API only reads and writes jobs, so it owns nothing and changes no schema
- [0021 An aggregator webhook may learn only which outlet its store belongs to](./0021-an-aggregator-webhook-may-learn-only-which-outlet-its-store-belongs-to.md) - one more fixed pre-sign-in lookup, from a provider's store id to the tenant and outlet, so a raw webhook is stored under the outlet's own isolation
- [0022 A new version of the till takes over only on its next launch](./0022-a-new-version-of-the-till-takes-over-only-on-its-next-launch.md) - the installed counter and kitchen app updates in the background and switches on its next launch, never by reloading a screen in use
- [0023 The guest menu keeps the full UI library and counts every script it ships](./0023-the-guest-menu-keeps-the-full-ui-library-and-counts-every-script-it-ships.md) - no smaller compatible library yet, a minimal router, and a build that fails when all emitted scripts together pass 120,000 bytes gzipped
- [0025 The till stores what it will send, and a refused change waits for a person](./0025-the-till-stores-what-it-will-send-and-a-refused-change-waits-for-a-person.md) - records and outbox ops are kept in wire form and checked against the contract on write; a refused op stays on the device, out of the push queue, until staff retry it; clearing the device wipes its identity with its counters
- [0027 Who a request acts for is read fresh on every request](./0027-who-a-request-acts-for-is-read-fresh-on-every-request.md) - the sign-in token names only the person and business; roles, account status and device revocation are read on every request; a person names the one outlet a request acts for; an answer holding a device secret is never kept for replay; a reused refresh secret ends the whole sign-in
