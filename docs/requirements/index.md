# Requirements

What the MVP must do, written so that tests can hold it to account. The design
it comes from lives in the [PRD](../BHOJNALYA_PRD.md) and the
[TRD](../BHOJNALYA_TRD.md). Edit those two only to fix an inconsistency within
one of them, never to make them match the code
([documentation layers](../conventions/documentation-layers.md)).

- [User stories (MVP)](./user-stories.md): 108 stories by persona and flow, each marked as from the PRD, from the TRD, new or open, plus the eight cross-app journeys the user-story tests drive first
